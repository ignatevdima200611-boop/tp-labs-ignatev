- **1. Чем ветка отличается от копии папки с проектом?**
Ветка — это путь на какой-то коммит в истории, который позволяет вести одновременную разработку с возможностью объединения изменений.
Копия папки — просто копирование файлов без связи с историей и без автоматического объединения правок.
ветка даёт возможность объединения разработки с контролем версий, а копия папки так не омжет.

- **2. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?**
История коммитов сохранится, так как вся информация о версиях находиться в папке .git.
Сами файлы проекта можно восстановить командами git checkout или git restore.
Потеряются только несохранённые изменения, которые не были закоммичены.

- **3. Зачем нужен Pull Request, если можно коммитить сразу в main?**
Pull Request даёт другим посмотреть на твой код и поправить его если нужно, и только после одобрения изменения попадают в main.
Если коммитить напрямую, можно случайно сломать проект.
